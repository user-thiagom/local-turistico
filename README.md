# Local Turístico 🏖️

Um projeto prático de **HTML e CSS** para exercitar habilidades de desenvolvimento web frontend.

## 📚 Sobre o Projeto

Este projeto consiste em um site informativo sobre destinos turísticos, especificamente sobre **Ipojuca**, um município do litoral de Pernambuco. O objetivo é praticar e consolidar conhecimentos em:

- ✅ Estruturação semântica com **HTML5**
- ✅ Estilização e layout com **CSS3**
- ✅ Organização de conteúdo

## 🗂️ Estrutura do Projeto

```
local-turistico/
├── index.html               # Página principal sobre Ipojuca
├── page-lagoa.html          # Página com detalhes de lagoa do carro (implementação futura)
├── pages.css                # Estilos compartilhados
├── assets/
│   ├── ipojuca/
│   │   ├── texto.md         # Descrições dos destinos
│   │   └── *.png            # Imagens dos locais
│   └── logo.png             # Logo do projeto
└── README.md                # Este arquivo
```

## 🎯 Conteúdo do Site

O site apresenta informações sobre destinos turísticos em Ipojuca:
- **Porto de Galinhas** - Famoso pelas piscinas naturais e recifes
- **Pontal de Maracaípe** - Conhecido pela beleza do pôr do sol
- **Praia de Muro Alto** - Perfeita para famílias e relaxamento
